# Mudasar Hayat Portfolio

A responsive one-page personal portfolio built with HTML, CSS and JavaScript.

## Files
- index.html — portfolio content
- style.css — responsive design
- script.js — mobile navigation and current year
- assets/samlocals-seo-certificate.png — SEO internship certificate

## Customize before publishing
1. Add your LinkedIn URL and GitHub URL in the Contact section.
2. Add project GitHub/demo links to the project cards.
3. Replace the MH avatar with a professional photo if desired.
4. Upload the folder to GitHub Pages, Netlify, or another static hosting service.

- assets/mudasar-profile.jpg — professional profile photo
